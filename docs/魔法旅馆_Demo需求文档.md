# 魔法旅馆 — Demo 需求与落地文档

> 参考 Steam《Innchanted》的核心体验，做独立开发向的垂直切片。  
> 形态：**3D 竖屏手机游戏**，设计分辨率 **750×1334**，斜俯视，不是第一人称。  
> 引擎与工程实现另文，本文只定玩法、镜头和操作体验。未写进「Demo 必做」的内容，默认不做。

---

## 0. 一句话目标

玩家在限时班次里，和一名 **按优先级干活的伙伴** 一起撑起 3D 魔法厨房：单击台子就跑过去做事，接单、做饭、兑药水、自己喝药开能力、把钱塞进箱子，同时应付小偷、堵路怪和挑剔客人。班次结束打星，夜里抽一张会影响明天的小抉择。

**Demo 成功标准：** 一个没玩过原作的人，打完 3 个班次后会说「又忙又乱，但很好玩」，而不是「这就是个做饭游戏」。

---

## 1. 原作乐趣拆解（只保留真正值钱的）

《Innchanted》不是「经营模拟」，而是 **Overcooked 式混乱 + 药水双用途 + 班次突发事件**。乐趣不来自数值成长，而来自：

| 乐趣来源 | 为什么好玩 | Demo 是否保留 |
| --- | --- | --- |
| 限时多任务 | 手比脑子慢，有「差点来不及」的紧张感 | **必留** |
| 药水既可上菜也可自己喝 | 同一资源要在「赚钱」和「开路/沟通」之间取舍 | **必留**（差异化核心） |
| 钱掉桌上还要再存箱 | 多一步搬运，制造额外忙乱 | **必留** |
| 突发事件打断节奏 | 刚要上菜，小偷来了 / 路被堵住 | **必留** |
| 客人有特殊规则 | 害羞要先喝魅力药、评委极不耐烦 | **必留**（各 1 种即可） |
| 每班次换布局 | 熟练套路立刻失效 | **精简留**：3 张手摆 3D 房间，不随机生成 |
| 夜晚抉择带来增益/恶搞减益 | 成本极低，梗感和重玩价值高 | **必留**（3 张牌即可） |
| 配方层层叠加 | 牛排 → 浇药水 → 附魔武器 | **精简留**：基础菜 + 浇药水；不做附魔武器 |
| 升级商店 / 野外钓鱼探索 / 装修 / 联机 / 28 天剧情 | 工期大，不是第一口乐趣 | **Demo 砍掉** |
| AI 伙伴按优先级自动捡漏 | 单人竖屏忙不过来；伙伴抢活也是乐趣 | **必留**（1 个，有优先级，不喝药） |

独立开发的原则：**系统要少，每个系统必须互相打架。**  
例如：魅力药水既要给害羞客人，又可能自己要喝；力气药水能砸开挡路石，但兑它会占用上菜时间。

## 2. Demo 范围

### 2.1 必做（Vertical Slice）

1. 单人、**竖屏触控**、3D 一层旅馆厨房 + 用餐区。设计稿 750×1334，锁定竖屏，不转横。
2. **1 个可玩流程：** 主菜单 → 班次 1 → 夜抉择 → 班次 2 → 夜抉择 → 班次 3（含评委）→ 结算。
3. 核心操作：**单击台子 / 客人 = 寻路 + 到达后做默认动作**；空地只走路；长按只用于危险或重复操作。不用虚拟摇杆。
4. **1 个 AI 伙伴**：按优先级表自己找活干，玩家可切倾向，不喝药水。
5. 完整服务闭环：客人入座 → 出单 → 制作 → 上菜 → 给贝壳 → 收贝壳存宝箱 → 客人离开。
6. 烹饪 2 种、药水 3 原色 + 3 混合、自己喝药 3 种效果。
7. 突发事件 4 种 + 特殊客人 2 种。
8. 班次计时、耐心条、1～3 星评价。
9. 夜晚 3 选 1 抉择，影响下一班次。

### 2.2 明确不做（避免范围蔓延）

- 升级、商店、永久数值成长
- 野外、钓鱼、探索、动物养成（袋熊护理等）
- 旅馆装修、换装、多角色剧情
- 联机 / 本地双人 / 多个 AI
- 随机换房、传送门网络、风管、多层楼
- 附魔武器流水线
- 存档跨天经营、28 天挑战
- 横屏、自由旋转镜头、第一人称、虚拟摇杆、走到台边还要再长按才拿普通物品、复杂刚体抛掷
- 高精度角色与完整动画体系（占位胶囊体 + 几个关键动作就够）
- 自定义键位、体感 / 捏合缩放、给 AI 下逐步微操（点每个菜命令它做）

以上全部记入文末「正式版候选」，Demo 验收通过后再挑。

### 2.3 呈现底线（3D 占位也要能玩）

- 设计分辨率 **750×1334 竖屏**。真机按高度适配，两侧或上下留安全区，不要拉伸变形。
- 班次里要稳定流畅；触控按钮按下到角色响应应在一帧手感内，不要「点了没动」。
- 美术可用方块 / 胶囊 / 色块家具占位，但 **信息必须一眼可读**：订单气泡、药水颜色、耐心条、事件警告、谁是小偷。
- 气泡和警告做在世界空间、始终朝向镜头，不要被柜子挡住，也不要被手指和底栏挡住。
- 关卡内容（刷客、事件、订单池、星级线）用配置表描述，方便改平衡；实现方式技术文档再定。

## 3. 3D 空间、镜头与移动端操作

目标机：竖着拿的手机。**不用虚拟摇杆。** 主操作一句话：**单击想要的台子，人就跑过去把当前该做的事做完。**

### 3.1 空间（按竖屏构图来摆）

- 一场班次 = **一间手摆好的 3D 房间**（厨房 + 用餐区），不是开放大地图。
- 房间要瘦高，不要横宽：大约 **7 米宽 × 12 米进深**。竖屏镜头才罩得住。
- 推荐动线：**近处（画面中下部）是厨房，远处（画面上部）是餐桌和门口**。客人从上往下走进来，玩家在中下段做饭，少左右大幅度来回。
- 家具是实心障碍：工作台、柜台、魔石都挡路，角色自动寻路绕开。
- Demo 三关换三套摆放，不换主题美术也行，但动线必须明显不同。

### 3.2 镜头

- **斜俯视，不让玩家转视角、不捏合缩放。**
- 竖屏几乎看不了「横着铺开的整屋」，所以：
  - 班次 1：尽量让关键台子都落在画面里。
  - 班次 2 / 3：镜头以玩家为中心小幅跟随，人留在可玩画面中下部。
- 跟随要钝：轻微延迟、限速，禁止猛甩。
- 家具别太高。必须高的东西，角色靠近时半透明。
- 屏幕外的客人 / 小偷 / 鸟 / AI，用屏边感叹号指过去。竖屏更容易漏掉门口，这条是刚需。

### 3.3 屏幕分区（设计稿 750×1334）

没有摇杆后，3D 能多占一截。底栏只留情境按钮：

| 区域 | 大约高度（设计像素） | 放什么 |
| --- | --- | --- |
| 顶安全 + HUD | 0～100 | 暂停、倒计时、贝壳。避开刘海 |
| 可玩画面 | 100～1180 | 3D 场景、世界气泡、选中描边、事件警告。**点击和长按都发生在这里** |
| 情境底栏 | 1180～1334 | 仅在需要时出现：投掷、喝药、停下、AI 倾向。全面屏 Home 条留空 |

真机更高：多出来的像素加顶底安全区。底栏始终在拇指区，但不常驻三大按钮。

### 3.4 单击做事 + 长按防误（主操作）

同时只能有 **1 个当前目标**（客人、工作台、地上物、事件单位）。单击可交互物既是选中，也是下令。

| 手势 | 落点 | 结果 |
| --- | --- | --- |
| **单击** | 食物台 / 烹饪台 / 餐桌 / 药剂机 / 坩埚 / 宝箱 / 客人 / 地上物 / 敌人 | **寻路过去 + 到达后立刻做当前默认动作**。已在交互距离内则马上做，不再走一遍。例外见下一行 |
| **单击** | 台上有货，且自己手里也有东西 | **只寻路走到跟前，不拿不放。** 到达后必须 **长按** 才拾取台上货物 |
| **单击** | 空地 | **只走路**到该点，到达后站定，不交互 |
| **单击** | 玩家自己 | 立即站住，取消当前寻路和进行中的加工 |
| **单击** | 另一个可交互物 | 立刻改去新目标（覆盖旧指令） |
| **单击** | AI 伙伴 | **不走过去。** 只显示它当前任务；再点底栏头像切倾向 |
| **长按**（约 0.28s） | 垃圾桶 / 魔石 / 自己（手上是药水时） | **危险操作**：丢弃、砸石、喝药。未按满不执行 |
| **长按** | 已在跟前、台上有货、自己手里也有东西 | **拾取台上货物**（只能拿 1 个，等于和台上互换） |

点在客人气泡上 = 点这个客人。点在 HUD / 底栏上不选场景。  
新单击立刻覆盖旧指令。从单击到角色迈步 ≤ 0.1s。  
双手最多持有 **1 个物品**。不可堆叠。

### 3.5 到达后的默认动作（不要再问一次）

食物台、烹饪台、餐桌是高频台：**空手时到达即拿，不要走到再长按。**  
唯一例外：手里已经有东西、台上也有货——先走过去站住，**长按才拿台上的**。

| 你手里 | 台上 / 对象 | 到达后默认 |
| --- | --- | --- |
| 空 | 食物台、香草箱、药剂机有库存、地上物、炉灶/锅/坩埚已完成的成品 | **自动拿** |
| 空 | 餐桌上有贝壳 | **自动捡** |
| 空 | 砧板有生肉、要切 | **自动切完**（出进度条，点自己可打断） |
| 有合法原料 | 空的砧板 / 炉灶 / 汤锅 / 坩埚 | **自动放下** 并开始做 |
| 有红药水 | 手上或台上的烤肉 | **自动浇成辣烤肉**（药水消耗） |
| 有客人要的菜 / 药 | 对应客人 | **自动上菜** |
| 有贝壳 | 宝箱 | **自动存入** |
| 有东西 | 台上也有一份可拿的 | **不自动拿、不自动换。** 走到跟前站住，动作提示「长按拾取」。长按后：台上进手里，手里放到台上（互换） |
| 任意 | 空地 | 只走到点，不拿不放 |
| 任意 | 敌人 | **自动连击**直到目标消失，或点自己站住 |
| 无魅力效果 | 害羞客人 | 走到跟前，气泡「它好害羞…」，**不揭示** |
| 有魅力效果 | 害羞客人 | 走到跟前并读心 |

炉灶、汤锅、坩埚：放下后自动计时；熟了且你 **空手** 时再单击该台取出。若手里有东西，熟了也只走到跟前，长按才拿出锅里的（手里的放到台上）。  
加工不要做成「空手还要走到再按住」：空手单击砧板带生肉 = 放下并切完。

### 3.6 长按只用在危险和重复

普通拿肉、出锅、上菜（空手或往空台放）**禁止** 要求长按。长按是防误触、换货和连做：

| 长按谁 | 条件 | 效果 |
| --- | --- | --- |
| 有货的柜台 / 炉灶 / 坩埚等 | 已在跟前，且自己手里也有东西 | **拾取台上货物**（与手里互换）。单击只会走过去，不会换 |
| 垃圾桶 | 手上有物；已在旁边或先单击走过去再按 | 丢掉。单击垃圾桶 **只寻路到跟前，不自动扔** |
| 魔石 | 有气力效果 | 砸开。没有气力则闪红。单击魔石只走到跟前 |
| 自己 | 手上是药水 | 喝掉（与底栏「喝药」相同） |
| 近处食物台 | 空手 | 再取一份（手满了无效） |
| 近处敌人 | — | 与单击连击相同，给已经贴脸时一个明确「继续打」 |

长按 0.28s 后指尖出圈，收满才执行，短震一次。

### 3.7 情境按钮

只在用得上时出现，约 96～112px：

| 按钮 | 何时出现 | 行为 |
| --- | --- | --- |
| 投掷 | 手上有物 | 朝当前目标工作台 / 客人短距扔出；没有目标则朝面朝方向扔到地上 |
| 喝药 | 手上是药水 | 等同长按自己 |
| 停下 | 正在寻路或自动连击 | 等同单击自己 |
| 伙伴 | 始终一个小头像 | 点开 AI 倾向（见第 8 节） |

暂停在左上角约 72px：继续 / 重开本班 / 回主菜单。班次中不要下滑暂停。

### 3.8 选中与到达判定

- 点选热区比模型大约 0.4m，竖屏远桌也要点得中。
- 当前目标描边 + 脚底圈 + 动作名（「拿生肉」「上菜」「长按拾取」）。玩家目标亮黄，AI 占用淡蓝。
- 重叠时取最近、最朝镜头的一个，0.15s 内不要来回跳。
- 到达：距离约 **1.2m** 且中间无墙即可做事，不需要对准正前方。
- 寻路被魔石 / 怪堵住：停在障碍前，目标闪红；有气力就长按石头，或改点别的路。

### 3.9 手感、菜单、调试

- 寻路起步利落，转角可切线，贴家具沿边滑，不要原地抖。
- 点错台子：单击自己取消；还没走到就不会拿。
- 拿错了：走到垃圾桶再长按丢掉，或投掷到地上再单击捡回。禁止软锁。
- 投掷：短抛物线，碰到目标台则放入，否则落地可捡。
- 全屏弹窗先抬起所有手指再收新点击。
- 振动：出发寻路、上菜成功、事件警告各一下，不要连震。
- 班次 1 引导只写：「点食物台，人会自己跑去拿。」只出现一次，可跳过。
- 主菜单 / 夜抉择 / 结算：大按钮，夜抉择点卡再确认。正文 ≥ 24px，倒计时 / 贝壳 ≥ 36px。
- PC 预览：左键单击 = 手机单击；左键按住 = 长按；右键投掷；Q 喝药；Esc 暂停。验收以真机竖屏为准。

## 4. 核心循环

```
班次开始（可能带着昨夜修正）
  → 客人从门口走进 3D 房间、自动入座出单
  → 玩家单击台子做事；AI 伙伴按优先级自己捡漏
  → 贝壳掉桌上 → 必须捡起塞进宝箱才算分
  → 脚本事件插入（偷、堵、特殊客）
  → 时间到
  → 按「已入箱贝壳 + 愤怒离店惩罚」打星
  → 夜晚 3 选 1
  → 下一班次（换房间布局）
```

单局时长：**90 秒**（班次 1 可 75 秒作教学）。  
同时在座客人上限：**3**。这是独立开发能控住的混乱度。

## 5. 物品与配方

颜色是信息设计的第一原则：红黄蓝必须高对比，3D 瓶体和头顶图标都要能认。

### 5.1 基础原料

| ID | 名称 | 来源 |
| --- | --- | --- |
| `meat_raw` | 生肉 | 肉箱，直接拿 |
| `herb` | 香草 | 香草箱，直接拿 |
| `potion_r` | 红药水 | 红色药剂机 |
| `potion_y` | 黄药水 | 黄色药剂机 |
| `potion_b` | 蓝药水 | 蓝色药剂机 |
| `shell` | 贝壳 | 客人付款后掉在桌上 |

### 5.2 加工

| 设施 | 输入 | 时间 | 输出 | 备注 |
| --- | --- | --- | --- | --- |
| 砧板 | 生肉 | 1.2s 自动 | 肉片 `meat_cut` | 单击到达后自动切完，点自己可打断 |
| 炉灶 | 肉片 | 2.0s 自动 | 烤肉 `steak` | 可焦：再放 3s 变 `steak_burnt`，只能扔垃圾 |
| 汤锅 | 香草 | 1.5s 自动 | 汤 `soup` | 不会焦 |
| 药剂机 | 无（需有库存） | 0.4s | 对应原色药水 | 每台库存 5 份，空了必须用「药桶」补满 |
| 药桶 | 玩家空手单击 | 1.0s | 给面前空药剂机 +5 | 到达后自动补；药桶不是便携物品 |
| 坩埚 | 两瓶不同原色药水 | 1.0s | 混合药水 | 同色或非法组合会弹回手上 |
| 垃圾桶 | 任意 | 即时 | 销毁 | **长按**才丢掉；单击只走到跟前 |

### 5.3 混合药水（核心差异）

| 配方 | 产物 ID | 上菜名 | 自己喝的效果 | 持续 |
| --- | --- | --- | --- | --- |
| 红+黄 | `potion_str` | 气力药剂 | 可砸碎「魔石障碍」 | 12s 或砸 1 次后消失 |
| 黄+蓝 | `potion_cha` | 魅力药剂 | 可对害羞客人「读心接单」 | 12s 或成功接单 1 次 |
| 红+蓝 | `potion_spd` | 疾行药剂 | 移速 +40% | 8s |

自己喝：手上是药水时，**长按自己** 或点底栏 **喝药**。0.3s 内不能接新寻路。伙伴不喝药。  
**冲突：** 同时只能有 1 个药剂效果。新喝的覆盖旧的。  
角色脚底或身周用对应颜色光圈，镜头再远也要看得出正在生效。

### 5.4 客人可点的菜（Demo 全表）

| 订单 ID | 需要提交的物品 | 基础贝壳 | 出现班次 |
| --- | --- | --- | --- |
| `steak` | 烤肉 | 8 | 1+ |
| `soup` | 汤 | 6 | 1+ |
| `potion_r/y/b` | 对应原色 | 5 | 1+ |
| `steak_hot` | 烤肉 + 红药水（对烤肉「浇」一次） | 12 | 2+ |
| `potion_str/cha/spd` | 对应混合药 | 14 | 2+ |
| `critic_set` | 辣烤肉 + 魅力药剂（两道，按气泡顺序上） | 25 | 仅班次 3 评委 |

浇药水：持有红药水，对柜台上或手里的烤肉交互 → 变成 `steak_hot`，药水消耗。Demo 只做红浇肉这一种，避免组合爆炸。

## 6. 客人系统

### 6.1 普通客人

- 门口生成 → 沿地面走到空桌坐下（自动入座，Demo 不做「领位」）。
- 坐下 0.4s 后出订单气泡（世界空间图标，不要长文字）。
- 耐心条默认 **20 秒**，随时间线性下降。
- 上对：桌上生成贝壳堆（视觉 1 个物体，金额 = 订单价 × 剩余耐心比例，最低 50%）。
- 上错：拒绝，耐心 -30%，物品仍在玩家手上。
- 耐心归零：愤怒离店，本班次「愤怒计数 +1」，桌上不给钱。
- 收完贝壳后 0.5s 起身离开，桌子空出。

贝壳必须玩家捡起再塞进 **宝箱** 才计入分数。桌上的贝壳班次结束时作废。  
这是刻意的「讨厌但好玩」：你明明做完了菜，还差最后几步。

### 6.2 特殊客人（Demo 只做 2 种）

**害羞精灵 `guest_shy`**

- 坐下后气泡是「???」。
- 玩家未处于魅力效果时，单击会走到跟前并弹出「它好害羞…」，不揭示订单。
- 喝魅力药后单击：寻路过去并读心，揭示真实订单（从本关订单池随机 1 个）。
- 揭示后按普通客人走。超时未揭示也愤怒离店。
- 班次 2 起出现，同时最多 1 个。

**食评家 `guest_critic`**

- 仅班次 3，开场 15 秒时强制刷 1 个。
- 耐心 16 秒，订单为 `critic_set`（两道，必须按顺序）。
- 成功：见评分。失败：本班次最高只能 2 星。
- 高帽 / 皇冠要在竖屏里一眼认出来，进门有警告横幅：「食评家来了」。

### 6.3 生成节奏

用关卡时间轴驱动，不要纯随机，保证每次 Demo 演示稳定。同时 3 座已满则该条延迟到有空位再生成。

| --- | --- | --- |
| 3s | 普通 | 烤肉 |
| 8s | 普通 | 红药水 |
| 16s | 害羞 | 揭示后从本关池抽 |
| 28s | 普通 | 辣烤肉 |
| 40s | 普通 | 汤 |
| 55s | 普通 | 气力药剂 |

## 7. 突发事件（Demo 的第二乐趣支柱）

事件不是装饰，必须 **打断当前最优路径**。每条都要：有预兆、有处理动作、有失败后果、处理完能立刻回到服务。

### 7.1 事件总表

| ID | 预兆 | 玩家对策 | 失败 | 建议出现 |
| --- | --- | --- | --- | --- |
| `thief` 狸猫神偷 | 门口闪红、3s 后进门冲向宝箱 | 单击神偷：寻路过去并自动连击 2 次（有气力效果 1 次） | 偷走宝箱内 30% 贝壳（至少 5，箱空则偷桌上贝壳） | 班次 2、3 各 1 次 |
| `blocker` 堵路魔 | 目标点冒烟 2s，刷出小怪占住通道 | 单击小怪：寻路过去并自动连击 3 次；有气力效果 1 次 | 一直堵到被打掉；不主动消失 | 班次 2 中段、班次 3 前段 |
| `magpie` 偷食鸟 | 尖叫，从窗外飞向「持物角色或桌上成品」 | 单击鸟驱赶；或先把物品放下 | 叼走 1 个物品并飞走销毁 | 班次 3 一次 |
| `dispenser_dry` 药剂见底 | 药剂机瓶体变暗、闪烁 | 单击药桶：走过去并补满 | 该颜色接不出来，等于软锁部分订单 | 靠库存自然发生，不算强制脚本 |

3D 里事件目标必须 **体型/颜色/动势** 和客人明显不同，并在屏幕边缘给感叹号，避免竖屏跟随镜头时漏掉门口的小偷。

### 7.2 事件出现时机

| 班次 | 时间 | 事件 |
| --- | --- | --- |
| 2 | 22s | 堵路魔，刷在炉灶到餐桌的最短路上 |
| 2 | 35s | 神偷 |
| 3 | 开场后较早 | 堵路魔 |
| 3 | 中段 | 神偷 |
| 3 | 后期 | 偷食鸟 |

规则：

- 同一时刻只激活 **1 个** 攻击型事件（神偷 / 魔 / 鸟），避免新手爆炸。
- 预兆必须 ≥ 2 秒，屏幕边缘感叹号指向场景里的目标。
- 神偷到达宝箱后有 1.5 秒「掏箱」，这段仍可被打断。
- 堵路怪优先堵「炉灶到餐桌」最短路，逼玩家改道或喝气力药。

### 7.3 夜晚抉择（班次之间，不是班次内）

班次结束后进入全屏 UI，三张卡选 1（排法见 3.9）。选完立刻进入下一班，不要做夜间 3D 漫游。

| 卡 | 文案方向 | 效果（下一班全程） |
| --- | --- | --- |
| 好好睡觉 | 「补个觉，明天手脚快些。」 | 移速 +15% |
| 熬夜炼金 | 「坩埚还在咕嘟。带着一瓶出门。」 | 开场手上自带 1 瓶随机混合药 |
| 听信巫师 | 「他说这是好运符。（大概）」 | 50%：本班耐心上限 +4s；50%：每隔 20s 强制跳舞 1.5s（不可操作，恶搞减益） |

班次 1 结束后选第一次，班次 2 结束后选第二次。不要做 5 种夜间活动，3 张就够演示「选择会闹出幺蛾子」。

## 8. AI 伙伴（按优先级自己干活）

Demo 始终带 **1 个** AI 伙伴（另一个胶囊体，主色与玩家不同）。玩家单击台子指挥自己；伙伴 **不等命令**，按优先级表抢当前最要紧的活。竖屏单人做不过来三桌，伙伴是乐趣的一部分，不是作弊器。

### 8.1 玩家怎么管它

不管细到「去切那块肉」。只切 **倾向**，用来重排优先级权重。

| 入口 | 行为 |
| --- | --- |
| 单击伙伴 | 不寻路。只显示当前任务（「去驱赶」「去存箱」「去补红药」） |
| 底栏「伙伴」头像 | 弹出三档倾向，点一下即换，不暂停游戏 |
| 长按伙伴 | 同样打开倾向面板（不要走到它身边） |

三档倾向：

| 倾向 | 何时用 | 对优先级的影响 |
| --- | --- | --- |
| **均衡**（默认） | 大多数时候 | 用下面总表原样 |
| **防卫** | 班次 2/3 事件多 | 事件类提到最高；没事件才做饭。仍会先把手里成品放到最近空台再冲过去 |
| **上菜** | 评委在、桌多 | 上菜 / 收贝壳权重大；药剂没全空不补；**事件仍可打断**（丢钱比少上一道更亏） |

倾向只改权重，不改「伙伴不会做的事」。

### 8.2 伙伴不会做（留给玩家的决策乐趣）

- **不喝任何药水**（气力 / 魅力 / 疾行都是玩家的选择）
- **不砸魔石**（开不开路是药水取舍）
- **不给害羞客人读心**（没魅力效果读不了；有也不抢）
- **不上评委的第二道** 若玩家已经选中评委或正拿着评委要的菜（避免两个人抢一道）
- **不抢玩家正在前往的目标**（你单击过、还在路上的台子 / 客人）
- 不把玩家手上的东西抢走，不从玩家占用的炉灶/砧板把半成品拿走

玩家点自己站住、伙伴不跟着停。夜抉择的移速 / 跳舞 **只作用于玩家**；玩家在跳舞时伙伴照常干活（这是减益里的甜头）。

### 8.3 优先级总表（高 → 低）

每隔约 0.3s 扫一次，取 **第一条合法任务** 执行。正在做的任务若仍合法，不要每帧换；只有出现 **更高优先级** 才打断。

**P0 紧急（可打断当前）**

| 序 | 任务 | 合法条件 |
| --- | --- | --- |
| 1 | 驱赶神偷 | 神偷已进门，且（距宝箱 < 4m 或正在掏箱） |
| 2 | 驱赶偷食鸟 | 鸟已锁定桌上成品，或锁定伙伴自己手上的东西 |
| 3 | 打堵路魔 | 怪挡在「从厨房到有订单的桌」的最短路上 |

手里正拿着成品又要去 P0：先放到最近空台 / 柜台，再冲。若神偷已经在掏箱（≤1.5s 窗口），拿着也去打，打完再回来拣。

**P1 收银与上菜**

| 序 | 任务 | 合法条件 |
| --- | --- | --- |
| 4 | 上菜 | 手上物品能完成某个在座订单（含评委当前要的那一道） |
| 5 | 收贝壳并存箱 | 任意桌上有未收贝壳 |
| 6 | 取成品去上 | 炉灶 / 坩埚 / 台面上已有客人正在等的成品，且伙伴空手 |

**P2 补给**

| 序 | 任务 | 合法条件 |
| --- | --- | --- |
| 7 | 补药剂机 | 某色库存 = 0，且本关仍会出该色订单 |
| 8 | 取出将焦的肉 | 炉灶上的肉再过 1s 会焦 |

**P3 备菜（闲下来才做）**

| 序 | 任务 | 合法条件 |
| --- | --- | --- |
| 9 | 做最缺的一道 | 看在座订单：缺烤肉就去拿肉切烤；缺汤就去煮；缺单色药就去接。一次只做 **一份** |
| 10 | 待命 | 回厨房待命点，面向餐桌 |

同优先级多条合法：选 **路径更短** 的。不要两头跑。

班次 1 特殊：P3 备菜关闭，只跑 P0（本关无事件所以空）+ P1 收银 + P2 补药。让玩家自己学会做饭。

### 8.4 占用与避让

- 伙伴认领一个台子 / 客人时，该物出 **淡蓝描边**（玩家目标是亮黄）。玩家仍可单击该目标：一旦下令，伙伴立刻放弃并重评优先级。
- 通道里让玩家：距玩家 < 0.8m 时伙伴停 0.3s 或侧让，不要把人挤进墙缝。
- 寻路失败（被石头堵住）：放弃该任务 2s，改做下一条。不在石头前发呆。
- 移速约为玩家的 **90%**，让人觉得是助手不是主角。
- 头顶常驻一个小图标：盾 = 防卫中，盘子 = 上菜，贝壳 = 存钱，瓶子 = 补药，刀 = 备菜。闲着就没有图标。

### 8.5 和突发事件的关系

- 神偷、鸟、堵路魔一旦合法进入 P0，伙伴 **必须** 去处理，除非玩家已经单击该目标并正在赶过去（玩家锁定则伙伴改做 P1）。
- 这是故意的：你在兑药时，伙伴会突然冲去打偷——你能从它头顶盾标读出来。
- 若倾向切到「上菜」且神偷刚进门但还远，仍走总表第 1 条（宝箱危险不可丢）。倾向不能关 P0。

### 8.6 失败表现（AI 可以笨，不能蠢）

允许：下手慢半拍、绕远路、先补药后上菜（均衡档）。  
不允许：把焦肉端给客人、两个人抢同一盘、站在石头前死循环、把玩家正在去拿的肉拿走、喝掉你刚兑的气力药。

## 12. 分阶段落地（按此顺序开发，每阶段都可运行）

原则：每个阶段结束时都能打开游戏「玩到一点新东西」，不要先空转架构两周。  
工程目录、框架、配置格式留给技术文档；这里只规定 **玩家能验到什么**。

### P0  空房间能跑

- 主菜单能进一间 3D 厨房空壳，画布 750×1334 竖屏。
- 斜俯视；**单击木箱 → 自动寻路过去并拿起方块**（举在身前）；再单击空台或地面木箱位置放下。
- 单击空地只走路；单击自己会站住，走到一半不会拿。
- 墙和地板有碰撞，寻路不穿模、不掉出世界。

**验收：** 真机或模拟器竖屏，不靠摇杆，单击就能拿起方块再放下。

### P1  做出第一份烤肉

- 肉箱、砧板、炉灶、垃圾桶能用。
- 生肉 → 切 → 烤，焦了能扔垃圾。
- 手上是什么，身前模型和/或 HUD 能看清。

**验收：** 固定流程做出烤肉。

### P2  客人闭环

- 1 张桌子、客人进门入座、头顶订单、耐心条。
- 上对给贝壳，捡起存箱得分，愤怒离店。
- 倒计时结束出结算（先只有贝壳数）。

**验收：** 90 秒内服务 3～5 个只要烤肉的客人，分能进箱子。单击客人会寻路过去上菜。

### P2.5  AI 只会收银

- 场上出现 1 个伙伴。班次 1 规则：只收桌上贝壳并存箱，不备菜。
- 玩家选中的桌子它不抢。头顶有贝壳图标。

**验收：** 你只管做菜上桌，它会把钱送进箱子；你单击某桌收钱时它改去另一桌。

### P3  药水

- 三色药剂机 + 库存 + 药桶补给。
- 坩埚双色合成。
- 喝药按钮：先做疾行（最好验证），再做气力砸石头。魅力先留接口。

**验收：** 兑出三瓶混合药；喝疾行明显变快；砸掉班次 2 的石头。

### P4  特殊客人 + 浇汁

- 害羞客人 + 魅力药读心。
- 红药浇烤肉 → 辣烤肉订单。

**验收：** 不喝魅力药接不了害羞单；浇对能上辣烤肉。

### P5  突发事件

- 神偷、堵路魔、偷食鸟，含预兆与失败惩罚。
- 警告条 + 警告音 + 目标可被斜俯视看见。

**验收：** 故意不处理会丢钱 / 堵路 / 丢菜；处理完能继续做菜。伙伴在神偷掏箱时会自己冲过去（除非你已经单击神偷、正在赶过去）。

### P6  三关 + 夜抉择 + 星级

- 三间不同动线的 3D 房间。
- 夜抉择 3 卡。
- 评委客人。
- AI 完整优先级 + 三档倾向可用。
- 菜单「开始 Demo」一键打完。

**验收：** 见下一节清单。

### P7  手感与可读性打磨

- 投掷入台、班次 1 一次性引导、暂停重开。
- 默认动作提示、长按丢弃圈、选中描边、伙伴任务图标可读。
- 安全区、刘海、Home 条下按钮仍好按。
- 占位换成可辨认的低模或清晰色块；补 SFX。
- 平衡：班次 2/3 让熟练者能 3 星、生手能 1 星通关。

**不要提前做：** 粒子海、对话系统、存档、设置里一堆选项。音量开关 + 全屏即可。

## 13. Demo 验收清单

找一个没看过本文的人玩一遍，不问你的情况下：

- [ ] 3 分钟内明白：做菜、上菜、收钱进箱
- [ ] 知道药水能喝，并且至少主动喝过一次去砸石头或读心
- [ ] 至少被 1 个突发事件打断过，并且知道该去打它
- [ ] 夜抉择选了「听信巫师」后，下一班能感觉到好事或蠢事
- [ ] 打完班次 3 有「高潮」而不是「重复两遍第一关」
- [ ] 全程没有必须重启才能解除的软锁（拿错东西永远扔不掉等）
- [ ] 不看数字也能靠颜色完成兑药
- [ ] 斜俯视下能分清玩家、伙伴、客人、小偷、炉灶；不会经常点错
- [ ] 空手单击食物台会走过去并自动拿；点空地只走；点自己取消
- [ ] 走到烹饪台有熟食且空手时自动拿起，不必再长按
- [ ] 手里拿着东西时点仍有货的台子：会走过去，**必须长按才拿台上的**（与手里互换）
- [ ] 丢掉东西必须长按垃圾桶；点自己能打断切菜
- [ ] 伙伴会自己收钱 / 在神偷出现时去打，且不抢你正在过去的目标
- [ ] 能切防卫 / 上菜倾向，并且看得出它在干什么
- [ ] 夜抉择三张卡好点，不会点滑或点到下一张

未勾上的项，优先改关卡摆放、镜头、按钮和反馈，不要加新系统。

## 15. 叙事（极轻，服务玩法）

Demo 不需要 NPC 走剧情。菜单一段话足够：

> 巫师把家族旅馆变成了会自己长石头、会招小偷的魔厨。  
> 今晚证明你能把它撑过三个班次——评委已经在路上。

角色是旅店学徒 + 1 个默默干活的伙伴。客人用体型 / 主色区分。不要在 Demo 里做对话树。

## 16. 正式版候选（Demo 过了再议，现在禁止开工）

按「乐趣/工时」大致排序，供以后挑，不进入当前迭代：

1. 本地双人同屏（可把 AI 位换成第二玩家）
2. 更多手摆 3D 关卡（传送带、单向门、拉杆改路）
3. 第 3、4 种特殊客人（急躁火灵、必须按座位的长者）
4. 附魔武器台

6. 贝壳商店：永久缩短烤时、多 1 格库存（这时才需要存档）
7. 给伙伴指定「只做这一件」（仍不要逐步微操）
8. 横屏模式、可微微旋转 / 拉近的镜头、完整动画与抛掷手感
9. 自定义操作
10. 野外 / 钓鱼 / 动物 —— 原作里也偏支线，独立开发最后再碰
11. 联机、装修、长剧情

## 17. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 做成无事件的过厨克隆 | P5 未完成不算 Demo；评测时必须被事件打断 |
| 竖屏看不全、门口来人没看见 | 房间瘦高 + 镜头跟随 + 屏边感叹号 + 警告音 |
| 误点台子跑去拿 | 单击自己取消，未到达不拿；热区不要叠在一起 |
| 误扔、误喝、误砸 | 这三件事必须长按满圈 |
| 手里有东西又点了有货的台 | 只走到跟前；长按才拾取（互换）。未按满不换 |
| 伙伴抢玩家的菜 | 玩家单击目标即锁定，伙伴让出；班次 1 关闭备菜 |
| 伙伴在石头前死循环 | 寻路失败放弃 2s，改下一条；伙伴不砸石头 |
| 刘海把暂停挤掉 | 按安全区排 HUD，P7 用真机验 |
| 镜头眩晕 | 不给玩家转镜头；跟随限速 |
| 占位几何体导致「这是什么台子」 | 颜色 + 头顶小图标 + 选中动作名 |
